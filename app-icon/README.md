# app-icon — آیکون اپلیکیشن «دزیان» (تاور دیفنس کارتونی)

آیکون مربع ۱:۱ به سبک کارتونی Kingdom Rush / Clash Royale: برج سنگی با توپ روی
سقف داخل سپر جادویی آبی، دو تانک دشمن کارتونی (قرمز و خاکستری تیره) در دو گوشهٔ
پایین، ستاره‌های طلایی شناور، آسمان آبی روشن با ابرهای پف‌دار و نوار چمن؛ عنوان
فارسی «دزیان» طلایی با دور مشکی در نوار پایین (خوانا ولی غیرغالب).

## فایل‌ها

| فایل | محتوا |
|---|---|
| `game_icon.png` | آیکون نهایی ۱۰۲۴×۱۰۲۴ PNG با عنوان «دزیان» — آمادهٔ آیکون APK |
| `game_icon_notext.png` | همان آیکون بدون عنوان (برای سایزهای خیلی کوچک / میان‌بر) |
| `preview_icon_sizes.png` | راستی‌آزمایی خوانایی در ۲۵۶/۱۲۸/۹۶/۴۸ پیکسل |
| `raw/game_icon_raw.png` | هنر پایهٔ تصویرسازی (بدون متن) |
| `iconproc.py` | برش مربع، مقیاس ۱۰۲۴، افزودن عنوان فارسی و ساخت پیش‌نمایش |

## نکتهٔ آیکون اندروید

- تصویر تمام‌بخش (full-bleed) است؛ برای آیکون adaptive اندروید همان لایهٔ
  foreground قابل استفاده است و ماسک گرد/مربع سیستم گوشه‌ها را می‌برد.
- عناصر اصلی داخل ناحیهٔ امن مرکزی (~۶۶٪ وسط) قرار دارند تا زیر ماسک‌ها نبرند.
- برای سایزهای ≤۴۸ پیکسل `game_icon_notext.png` پیشنهاد می‌شود.

## خطوط تولید

```bash
pip install pillow arabic-reshaper python-bidi
python3 iconproc.py
```

عنوان با فونت `Vazirmatn-FD-Bold` (از `games/dejban/godot/assets/fonts/`) و
`arabic_reshaper + python-bidi` رندر می‌شود: پرکردن طلایی، دور مشکی ضخیم و سایهٔ تخت.
