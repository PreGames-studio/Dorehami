# art-releases — بسته‌های_zip دارایی هنری

این پوشه فقط برای ارائهٔ لینک دانلود مستقیم دارایی‌های هنری بازی تاور دیفنس است
(آپلود asset روی Releases از محیط ساخت امکان‌پذیر نبود). هر zip مجموعهٔ خروجی‌های
نهایی PNG آمادهٔ بازی است؛ فهرست محتویات داخل هر zip در CONTENTS.txt آمده است.

- `dorehami-td-art-v1.zip` — قلعهٔ ۵ سطحی، صفحه‌های پیروزی/شکست/فروشگاه، کارت
  آیتم و آیکون اپ (نسخهٔ ادغام‌شده در main).
