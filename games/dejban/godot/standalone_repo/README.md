# دژبان · نگهبانان آخرین دژ

بازی دفاع از قلعه با رابط فارسی و راست‌چین، نوشته‌شده با **Godot 4.3** برای دسکتاپ و اندروید.
دشمنان از دروازه می‌آیند، تو برجک می‌سازی، موج‌ها را پس می‌زنی و ستاره‌ها را خرج باز کردن
نقشه‌ها و سلاح‌های تازه می‌کنی.

> این پروژه از صفر ساخته شده است. قواعد همکاری در [`RULES.md`](../RULES.md) نگه داشته می‌شود.

## اجرا

نیازمندی: **Godot 4.3** یا بالاتر (نسخهٔ استاندارد، نه .NET).

```bash
godot --path .              # اجرای بازی
godot --headless --path . --import   # فقط ایمپورت دارایی‌ها
```

یا پوشهٔ پروژه را در Godot باز کن و دکمهٔ Run را بزن.

## تست خودکار

تست بدون رابط گرافیکی، ساختار داده‌ها، درستی ۲۸ نقشه، ترکیب ۳۰ موج و کامل بودن همهٔ
تصویرها و صداها را بررسی می‌کند و در پایان کد خروج ۱ می‌دهد اگر چیزی خراب باشد:

```bash
godot --headless --path . res://tests/headless_test.tscn
```

همین تست در گردش‌کار `Godot verify` روی هر فشار به شاخه‌ها اجرا می‌شود.

## ساختار پروژه

```
├── project.godot            تنظیمات پروژه (۱۲۸۰×۷۲۰ افقی، ۶۰ فریم، GL Compatibility)
├── export_presets.cfg       پیش‌فرض خروجی اندروید
├── default_bus_layout.tres  اتوبوس‌های صدا: Master، SFX، Music
├── scenes/                  صحنه‌های ورودی: منو، اطلس، زرادخانه، تنظیمات، نبرد
├── src/
│   ├── autoload/            Game (پیشرفت و ذخیره)، Audio (صدا)، Style (تم)، Ui (کارخانهٔ واسط)
│   ├── data/                Assets (فهرست هنر)، Balance، Weapons، Enemies، Maps، GameMap
│   ├── game/                Battle، Ground، Tower، Enemy، Projectile، Keep، BuildGhost
│   ├── fx/                  Fx (انفجار و جرقه) و FloatingText
│   └── ui/                  Hud، پنل برجک، منوها، نقشهٔ بندانگشتی
├── assets/
│   ├── fonts/               وزیرمتن (ارقام فارسی، مجوز OFL)
│   ├── sounds/              ۱۶ جلوهٔ تولیدی، ۷ کلیپ رزمی CC0 و دو لوپ موسیقی
│   ├── icons/               آیکون ۱۸ سلاح و آیکون‌های واسط
│   └── sprites/             زمین، دکور، دژ، برجک‌ها، دشمنان، گلوله‌ها و جلوه‌ها
├── tests/                   تست بدون رابط گرافیکی
└── tools/                   مولد هنر، صدا و فهرست دارایی‌ها (پایتون)
```

## بازی

- **۱۵ نقشه** در چهار زیست‌بوم (چمنزار، جنگل، کویر، برف). تنها نقشهٔ اول از آغاز باز است؛
  هر نقشهٔ بعدی فقط با پیروزی در نقشهٔ قبلی باز می‌شود و هزینهٔ ستاره‌ای ندارد.
- **مسیر دشمن** برای هر نقشه از بذر خودش ساخته می‌شود: پیچ‌وخم، مشعل‌های کنار راه و
  دروازهٔ ورودی. روی مسیر و زمین‌های پرشیب نمی‌شود ساخت.
- **۱۸ برجک** در چهار رفتار: تک‌هدف، ناحیه‌ای، زنجیره‌ای و همه‌جانبه؛ هر برجک تا
  **سطح ۵** ارتقا می‌یابد و هر ارتقا آسیب، برد و سرعت شلیک را بهتر می‌کند.
- **۱۰ دشمن**: سرباز، دونده، زره‌پوش، سپردار، کمانگیر، درمانگر، بال‌دار، فرمانده، غول و
  سردار. درمانگر هم‌نوعان را درمان می‌کند و فرمانده آن‌ها را تندتر.
- **۳۰ موج** در هر نقشه؛ هر ۱۰ موج یک سردار می‌آید. پایان هر موج پاداش سکه دارد و
  رسیدن به موج‌های ۱۰، ۲۰ و ۳۰ ستاره می‌دهد (نقشه‌های آخر ستارهٔ پیروزی هم دارند).
- **دژ** ۲۰ جان دارد؛ هر دشمنِ رسیده یک جان و سردار پنج جان می‌گیرد.
- پیشرفت، ستاره‌ها، نام نگهبان و تنظیمات صدا روی دستگاه ذخیره می‌شوند
  (`user://dezhban_save.json`).

## هنر و صدا

اسپرایت‌ها و صداهای رابط با اسکریپت ساخته می‌شوند؛ صداهای رزمی از ضبط‌های CC0 و با
سطح صدای کنترل‌شده انتخاب شده‌اند. منشأ، مجوز، مدت و مشخصات آن‌ها در
`assets/sounds/combat/SOURCES.md` آمده است.

```bash
pip install -r tools/requirements.txt
python3 tools/gen_sprites.py           # اسپرایت‌ها، آیکون سلاح‌ها و آیکون اپ
python3 tools/gen_sounds.py            # جلوه‌های رابط + دو لوپ موسیقی (از سازندهٔ پایین)
python3 tools/compose_music.py --track all --analyze   # موسیقی: چهار طرحِ کاندید در soundsheets/
python3 tools/gen_assets_manifest.py   # src/data/Assets.gd از روی فایل‌های موجود
```

کد بازی فقط با کلیدهای منطقی مثل `units/grunt` یا `towers/head_bow` کار می‌کند، پس اگر
هنری را با پروندهٔ خودت عوض کنی، فقط کافی است همان نام را بگذاری و مانیفست را دوباره
بسازی. اگر کلیدی گم شود، `Assets.tex` نزدیک‌ترین هنر همان خانواده را می‌آورد و تست
بدون رابط، کمبود را با خطا اعلام می‌کند.

## ساخت فایل نصبی اندروید

ساخت APK فقط **با درخواست** انجام می‌شود، نه با هر تغییر:

- از زبانهٔ Actions گردش‌کار `Android APK` را دستی اجرا کن، یا
- کامیتی بزن که در پیامش نشان `[build-apk]` باشد.

خروجی هم به‌عنوان اثر (Artifact) همان اجرا و هم در انتشار ثابت `apk-latest` می‌نشیند،
پس لینک دانلود ثابت می‌ماند:

```
https://github.com/pregamesstudio/Dezhban/releases/download/apk-latest/dezhban.apk
```

برای ساخت محلی: Android SDK و JDK ۱۷ یا بالاتر نصب کن، بعد از زبانهٔ Editor گزینهٔ
*Install Android Build Template* را بزن (اگر لازم شد) و از Project ▸ Export خروجی بگیر.
