# item-cards — کارت آیتم «افزایش اعتبار (PRESTIGE BOOST)»

کارت ارتقای آیتم برای بازی موبایل کارتونی تاور دیفنس، سبک Kingdom Rush / Clash Royale:
۵۱۲×۵۱۲ پیکسل، PNG شفاف (RGBA)، نسبت ۱:۱ — آمادهٔ Construct 3.

## فایل‌ها

| فایل | محتوا |
|---|---|
| `prestige_boost_card.png` | کارت نهایی ۵۱۲×۵۱۲ شفاف |
| `preview_prestige_boost.png` | پیش‌نمایش کارت روی زمینهٔ شطرنجی (نمایش شفافیت) |
| `raw/medal_icon_raw.png` | آیکن مدال خام (پس‌زمینهٔ ماژنتا) |
| `icproc.py` | تولید رویه‌ای کارت از raw/ |

## چیدمان کارت

- بدنهٔ فلزی آبی تیره، گوشه‌های گرد، حاشیهٔ طلایی با لبهٔ مشکی ضخیم، پرچ‌های طلایی چهار گوشه
- آیکن بالای وسط: مدال نظامی طلایی با ستارهٔ بزرگ، هالهٔ جادویی آبی درخشان، ستاره‌های طلایی شناور
- نام آیتم: «افزایش اعتبار» سفید پررنگ با دور مشکی
- سطح: «سطح ۱۵ / ۵۰» طلایی
- نوار پیشرفت: گرادیان آبی→طلایی به میزان ۳۰٪ (۱۵ از ۵۰)
- پاداش: «+۱۵۰ سکه شروع» سبز با آیکن سکه
- هزینه: «۱۰» با آیکن ستاره
- دکمهٔ پایین: گرادیان طلایی با متن «ارتقا»
- بدون گرادیان خارج از دکمه/نوار/درخشش؛ طراحی تخت با خطوط دور مشکی ضخیم

## خطوط تولید

```bash
pip install pillow numpy arabic-reshaper python-bidi
python3 icproc.py
```

- کارت در مقیاس ۴× (سوپرسمپل) کشیده و با LANCZOS به ۵۱۲ رسانده می‌شود (لبه‌های نرم).
- متن فارسی با فونت `Vazirmatn-FD` (از `games/dejban/godot/assets/fonts/`) و
  `arabic_reshaper + python-bidi` رندر می‌شود (Pillow بدون raqm).
- آیکن مدال از `raw/` با حذف پس‌زمینهٔ ماژنتا و لبهٔ نرم (حفظ هالهٔ آبی) برش می‌خورد.
