# دورهمی 🎲

اپ اندروید برای همهٔ بازی‌های دورهمی در یک جا: ورق (حکم)، نمایشی (پانتومیم)، فکری (شطرنج) و هر بازی
بعدی که اضافه شود.

| حالت بازی | چطور؟ | بدون اینترنت؟ |
|---|---|---|
| اتاق بلوتوثی | یک گوشی میزبان می‌شود، بقیهٔ نزدیک‌ها وصل می‌شوند | ✅ آفلاین |
| اتاق آنلاین با دوستان | کد اتاق روی سرور خودمان (VPS ایرانی) | ❌ |
| حریف تصادفی / تورنمنت | صف سرور | ❌ |

**وضعیت:** فاز طراحی + نخستین بازی. معماری کامل شده و در `docs/` است. **حکم** اولین قطعه‌ای است که
ساخته شده: قواعد کامل (با گزینه‌های خانه‌گی)، ربات‌های قطعی، تست‌های قرارداد و صفحهٔ بازی با
رابطِ فارسی/راست‌به‌چپ — فعلاً روی یک دستگاه (شما + سه ربات). بلوتوث و آنلاین بعد از `core/session`
به همین بازی وصل می‌شوند (ترتیب ساخت در `docs/ROADMAP.md`).

### حکم (حکم)

```
./gradlew :games:hokm:core:test     # قواعد، حریمِ اطلاعات، قطعیت، امتیاز، ربات
```

* قواعدِ کاملِ چهارنفره با منبعِ معتبر: `docs/HOKM_RULES.md`
* گزینه‌های خانه‌گی: امتیازِ هدف، پایانِ دست با ۷ یا ۱۳ دست، «حکمِ لازم»، امتیازِ کوت و حاکم‌کُتی،
  مهلتِ هر نوبت.
* ربات‌های قطعی (بدون مصرفِ تصادف) و ۱۳ افکتِ صوتیِ اختصاصی.
* تصویرِ زمینهٔ میز و پشتِ کارت با هوش مصنوعی، روی کارت‌ها با وکتورِ دقیق.

## ساخت و تست (خلاصه)

نیازمندی: JDK 17 + Android SDK (compileSdk 36). دیتابیس اختیاری است.

```bash
./gradlew checkAll            # همهٔ تست‌های JVM (چیزی که CI اجرا می‌کند)
./gradlew :app:assembleDebug  # ساخت APK: app/build/outputs/apk/debug/
./gradlew :server:run         # اجرای سرور روی http://localhost:8080
```

روی ماشین کم‌حافظه:

```bash
./gradlew checkAll -Dorg.gradle.jvmargs="-Xmx1200m -XX:MaxMetaspaceSize=512m" \
  -Dkotlin.compiler.execution.strategy=in-process
```

## ساختار پوشه‌ها

```
core/protocol    پیام‌ها و قالب حرف‌زدن قطعه‌ها (بدون وابستگی)
core/gamesdk     قرارداد بازی: قواعد، موتور، قطعیت، رکورد قابل اثبات
core/session     چرخهٔ اتاق: لابی، نوبت، تایمر، ریسینک (مشترک بین آفلاین/آنلاین)
core/testkit     فیک‌های درون‌حافظه برای تست سریع
core/uikit       تم Compose، راست‌به‌چپ، اجزای مشترک رابط کاربری
transport/api    قرارداد «لوله» (ارتباط)
transport/nearby بلوتوث/وای‌فای دایرکت — بازی آفلاین
transport/online وب‌سوکت + صف حریف تصادفی
games/<بازی>/core  قواعد یک بازی (مستقل، مالک: یک نفر)
games/<بازی>/ui    صفحه‌های همان بازی
server           داور آنلاین: اتاق، صف، ذخیره و راستی‌آزمایی نتیجه
app              اپ اندروید: ناوبری، لابی، تنظیمات
docs             همین اسناد + تصمیم‌ها (ADR)
```

قانون اصلی: `games/*` به هیچ بازی دیگر وابسته نیست؛ هر بازی یک پوشهٔ قابل واگذاری است.
