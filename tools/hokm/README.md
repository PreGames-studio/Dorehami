# ابزارهای کمکیِ حکم

این پوشه **منشأِ فایل‌های باینریِ** بازی است. هیچ فایلِ صوتی یا تصویری در مخزن نیست مگر اینکه
این‌جا راهِ ساخته شدنش نوشته شده باشد (قانونِ «هیچ فایلی بدون منشأ» در `AGENTS.md`).

## ۱. `make_sfx.py` — افکت‌های صوتی

```bash
python3 tools/hokm/make_sfx.py
```

۱۳ افکتِ صوتی را در `games/hokm/ui/src/main/res/raw/` می‌سازد:

| فایل | کجا پخش می‌شود |
|---|---|
| `hokm_card_deal.wav` | پخشِ کارت |
| `hokm_card_played.wav` | بازی کردنِ هر کارت |
| `hokm_trick_won.wav` | گرفتنِ یک دست |
| `hokm_trick_ruffed.wav` | بریدنِ دست با حکم |
| `hokm_trump_set.wav` | تعیینِ حکم |
| `hokm_hand_won.wav` | بردنِ یک دست (۱ امتیاز) |
| `hokm_hand_lost.wav` | باختنِ یک دست |
| `hokm_kot.wav` | کوت (۲ امتیاز) |
| `hokm_hakem_koti.wav` | حاکم‌کُتی (۳ امتیاز) |
| `hokm_match_won.wav` | بردنِ بازی |
| `hokm_match_lost.wav` | باختنِ بازی |
| `hokm_your_turn.wav` | شروعِ نوبتِ شما |
| `hokm_invalid_move.wav` | حرکتِ غیرمجاز |

**بدون هیچ وابستگی‌ای** (فقط کتابخانهٔ استانداردِ پایتون: `math`/`wave`/`struct`) و **کاملاً قطعی**
(`random.seed(7)`): اجرای دوباره، همان ۱۳ فایل را بایت‌به‌بایت تولید می‌کند. پس تفاوتِ صداها در
گیت‌هاب فقط به تغییرِ خودِ اسکریپت مربوط است، نه به نویزِ محیط.

اگر خواستید صدایی را عوض کنید، عددها را در تابعِ همان صدا تغییر دهید و دوباره اجرا کنید؛ نیازی به
هیچ نرم‌افزارِ صوتی‌ای نیست. صداها با **سنتزِ افزایشی** (چند هارمونیک + پوشِ ADSR) و کمی نویز برای
حسِ «کاغذ و نمد» ساخته شده‌اند.

## ۲. `hokm.py` و `scenarios.py` — شبیه‌سازِ مستقلِ قواعد

یک پیاده‌سازیِ دوم و کاملاً جدا از کاتلین، فقط برای **راستی‌آزماییِ دوسویه**:

```bash
cd tools/hokm && python3 scenarios.py
```

* `hokm.py`: مدلِ بازی (پخش، تعیینِ حاکم، قواعدِ خال، حکمِ لازم، امتیاز و کوت) به زبانِ پایتون.
* `scenarios.py`: سناریوهای از پیش‌نوشته (طولانی‌ترین خال، بُرندگی، کوت، حاکم‌کُتی، امتیازِ هدف،
  حالتِ ۱۳ دست، یارِ حاکم کارت نمی‌گیرد) و ۲۰۰۰ بازیِ تصادفی با ربات.

هر وقت قواعد در کاتلین تغییر کرد، این شبیه‌ساز را هم به‌روز کنید: اگر دو پیاده‌سازیِ مستقل روی یک
سناریو هم‌نظر نباشند، یعنی یکی از آن‌ها اشتباهی دارد. این ارزان‌ترین راه برای پیدا کردنِ باگِ
قواعد پیش از انتشار است.

| `games/hokm/ui/src/main/res/drawable-nodpi/hokm_table_felt.jpg` | ۱۰۲۴×۱۲۸۰ | ۲۸۲ کیلوبایت | میز با روکشِ نمدِ سبزِ تیره و کادرِ چوبی |

روی کارت‌ها با کد ترسیم می‌شوند (`HokmCardFace.kt`) تا در هر تراکمی تیز بمانند.
