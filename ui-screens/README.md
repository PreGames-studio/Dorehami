# ui-screens — صفحه‌های پیروزی / شکست (تاور دیفنس)

پس‌زمینه‌های تمام‌صفحهٔ کارتونی (همان سبک قلعه‌های `castle-sprites/`، الهام‌گرفته از
Kingdom Rush / Clash Royale)، نسبت ۱۶:۹، ۱۹۲۰×۱۰۸۰ پیکسل، PNG — آمادهٔ Construct 3.

## فایل‌ها

| فایل | محتوا |
|---|---|
| `victory_screen.png` | قلعهٔ پیروز روی تپه، پرچم‌های طلایی، آتش‌بازی آبی/طلایی/بنفش، سربازهای چیبی جشن‌گیرنده، رون‌های طلایی درخشان، آسمان آبی با ابر پف‌دار و پرتو خورشید، ستاره‌های شناور |
| `defeat_screen.png` | قلعهٔ ویران با برج‌های شکسته، آسمان طوفانی بنفش با صاعقه، سربازهای غمگین نشسته، آوارهٔ سوختهٔ تانک و جیپ با شعلهٔ نارنجی، رون‌های محو، دود و ابر تیره |
| `upgrade_shop.png` | صفحهٔ فروشگاه ارتقا: نوار بالا (عنوان «ارتقاها»، شمارندهٔ سکه ۱۲۵۰ و ستاره ۴۵، دکمهٔ بازگشت و تنظیمات)، شبکهٔ ۲×۳ کارت ۲۵۰×۳۰۰ (افزایش اعتبار هایلایت‌شده با نوار پیشرفت، سکه شروع، قدرت سرباز، سرعت جیپ، زره تانک، آسیب برج)، دکمه‌های پاداش روزانه/پیشنهاد ویژه با نشان اعلان، پس‌زمینهٔ فلزی آبی تیره با الگوی نظامی ظریف و قاب طلایی |

## ناحیه‌های امن چیدمان

- **متن عنوان:** بالای وسط (حدود ۲۰٪ بالایی تصویر) در هر دو صفحه آسمانِ خلوت است.
- **دکمه‌ها (بازی مجدد / منوی اصلی، تلاش مجدد / منوی اصلی):** نوار پایینی
  (حدود ۱۲٪ پایینی) در هر دو صفحه ساده و بدون جزئیات مهم است.
- هیچ متن، حرف، عدد، لوگو یا دکمهٔ قابل مشاهده‌ای داخل خود تصویرها نیست.

## خطوط تولید

- `raw/` — خروجی خام تصویرسازی (صفحه‌ها ۱۳۷۶×۷۶۸؛ آیکن‌های فروشگاه با پس‌زمینهٔ ماژنتا).
- `uiproc.py` — برش وسط به نسبت ۱۶:۹، مقیاس LANCZOS به ۱۹۲۰×۱۰۸۰ و شارپ ملایم
  (برای `victory_screen.png` و `defeat_screen.png`).
- `shopproc.py` — تولید رویه‌ای `upgrade_shop.png` در سوپرسمپل ۲×: بدنه/قاب/الگو،
  نوار بالا، شبکهٔ کارت‌ها با آیکن‌های برش‌خورده از raw/ (مدال از `item-cards/raw/`)،
  متن فارسی با وزیرمتن FD + arabic_reshaper/bidi، و دکمه‌های پایین.

```bash
pip install pillow numpy arabic-reshaper python-bidi
python3 uiproc.py
python3 shopproc.py
```
