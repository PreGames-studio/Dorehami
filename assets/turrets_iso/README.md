# برج‌های دفاعی ایزومتریک — اسپرایت‌شیت ۱۲۸×۱۲۸

چهار برج دفاعی با نمای **از بالا و کمی مایل (ایزومتریک ۲:۱)**، سبک کارتونی با خط دور
ضخیم مشکی، تم نظامی-علمی تخیلی و پالت سبز ارتشی / آبی نفتی / خاکستری تیره با جزئیات
نارنجی و قرمز درخشان. هر برج یک **پایهٔ هشت‌ضلعی ثابت** دارد و فقط **سرِ گردان** روی آن
می‌چرخد؛ همان قراردادی که در بازی‌های تاور دیفنس برای نشانه‌گیری لازم است.

| شناسه | نام | اسلحه | رنگ تأکید | افکت شلیک |
|---|---|---|---|---|
| `machinegun` | مسلسل سنگین | دو لولهٔ سنگین روی سپر زرهی | نارنجی/زرد | شعلهٔ ستاره‌ای + پوکه + دود |
| `laser` | توپ لیزر | لنز سبز با سیم‌پیچ انرژی | سبز | پرتوی سبز با هاله و حلقهٔ شارژ |
| `rocket` | سکوی موشک | چهار لولهٔ موشک + رادار | قرمز | دو گلولهٔ آتش از دهانه‌ها |
| `cannon` | خمپاره‌انداز سنگین | لولهٔ کوتاه کلفت با دهانهٔ رو به بالا | کهربایی | گلولهٔ آتش بزرگ + دود |

## فایل‌ها

همهٔ فایل‌ها PNG/RGBA با **پس‌زمینهٔ کاملاً شفاف** و فریم‌های `۱۲۸×۱۲۸` هستند.

| فایل | فریم | اندازهٔ شیت | FPS | پخش |
|---|---:|---:|---:|---|
| `<tower>_idle.png` | ۴ | 512×1024 | ۱۰ | حلقه‌ای — چرخش آرام ±۳ درجه |
| `<tower>_aim.png` | ۲ | 256×1024 | ۱۲ | حلقه‌ای — نشانه‌گذاری و رتیکل |
| `<tower>_fire.png` | ۴ | 512×1024 | ۱۴ | یک‌بار — پس‌نشینی و شعله |

`atlas_towers_iso.png` (+ `.json`) یک شیتِ مادر برای پیش‌نمایش سریع است و
`manifest.json` فرادادهٔ کامل (ابعاد فریم، محور چرخش، ترتیب جهت‌ها، فهرست فریم‌ها، پالت).

### چیدمان شیت

هر شیت یک **شبکه** است: **ردیف = جهت** (۰..۷) و **ستون = فریم**.

```
              frame 0   frame 1   frame 2   frame 3
  dir 0 (E)  [ 128x128 ][ 128x128 ][ 128x128 ][ 128x128 ]
  dir 1 (SE) [        ...                                ]
  ...
  dir 7 (NE) [        ...                                ]
```

جهت‌ها ساعت‌گرد از شرق: `0=E، 1=SE، 2=S (رو به دوربین)، 3=SW، 4=W، 5=NW، 6=N، 7=NE`.
در بازی، زاویهٔ هدف را به نزدیک‌ترین مضرب ۴۵ درجه گرد کن، فریم ستون را با FPS جلو ببر و
کل اسپرایت را حول **محور چرخش `(64, 75)`** بگذار (پایین کادر، مرکز حلقهٔ گردان).

> فایل‌های قدیمی `assets/turrets/` (فریم ۶۴×۶۴، نوار افقی، نمای بالا) دست‌نخورده‌اند؛
> این مجموعه جدا و مستقل است.

## ساخت مجدد و بررسی

```bash
pip install pillow
python3 tools/generate_iso_tower_sprites.py              # شیت‌ها + اطلس + مانیفست + پیش‌نمایش‌ها
python3 tools/generate_iso_tower_sprites.py --no-gif     # بدون GIF (سریع‌تر)
python3 tools/generate_iso_tower_sprites.py --only laser # فقط یک برج
```

مولد در پایان خودش خروجی را بازرسی می‌کند: اندازهٔ فریم‌ها، RGBA بودن، خالی نبودن فریم‌ها و
**یکسان ماندن پیکسل‌های پایه در همهٔ فریم‌ها** (یعنی پایه هیچ‌وقت تکان نمی‌خورد). اگر این
بررسی رد شود، اجرا با کد ۱ تمام می‌شود؛ همان چیزی که CI می‌تواند اجرا کند.

## پیش‌نمایش‌ها

`previews/overview.png` (چهار برج × سه حالت)، `previews/directions.png` (هشت جهت)،
`previews/sheet_<tower>.png` (شیت کامل هر برج) و `previews/anim_<tower>.gif`
(چرخش + شلیک روی شطرنجی) و `previews/scene.png` (نمای داخل بازی روی زمین ایزومتریک).

## نمونهٔ وصل‌کردن (Godot 4)

```gdscript
const FRAME := 128
var tex: Texture2D = load("res://assets/turrets_iso/machinegun_idle.png")

func frame(dir: int, f: int) -> AtlasTexture:
    var a := AtlasTexture.new()
    a.atlas = tex
    a.region = Rect2(f * FRAME, dir * FRAME, FRAME, FRAME)
    return a

# Sprite2D: centered = true، offset = Vector2(0, FRAME/2 - 75) تا محور چرخش روی حلقه بنشیند
func face_target(target: Vector2) -> void:
    var d := Vector2(target.x - global_position.x, (target.y - global_position.y) / 0.5)
    dir = int(round(rad_to_deg(d.angle()) / 45.0)) % 8   # 0=شرق تا 7=شمال‌شرق
```

همین قرارداد در هر موتوری که AtlasTexture/Region دارد کار می‌کند؛ کافی است ردیف را با
جهت و ستون را با فریم انتخاب کنی.
