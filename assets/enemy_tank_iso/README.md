# دشمن تاور دیفنس: تانک سنگین — اسپرایت‌شیت ۱۲۸×۱۲۸ ایزومتریک

یک ماشین جنگی کارتونی و چاق با دوربین **از بالا و کمی مایل (ایزومتریک ۲:۱)**؛ همان
دوربینی که در پک برج‌های `assets/turrets_iso/` استفاده شده، تا دشمن و برج‌ها روی یک
زمین کنار هم بنشینند.

- زره **کرم/سفید** با لبه‌های روشن و درزهای پنل، شاسی و اتصالات مکانیکی **خاکستری تیره**،
  نوارها و چراغ‌های **نارنجی/قرمز درخشان**.
- دو **چشم گنبدی درشت** روی صفحهٔ صورت با ابروی فلزی کج: بامزه ولی ترسناک.
- لامپ‌های نارنجی در دو گوشهٔ صورت و چراغ‌های قرمز/نارنجی روی پهلوی هر شنی.
- شنی‌زنجیر با تسمهٔ روشن، دندانه‌های متحرک و چهار چرخ غلتان؛ بدنه با تعلیق نرم تکان می‌خورد.
- **حمله**: لنز وسط صورت شارژ می‌شود و پرتوی **لیزر قرمز** با هاله، مغز سفید-داغ، شکوفهٔ
  دهانه و دود بیرون می‌زند. اگر صورت رو به دوربین نباشد، پرتو از گنبد پرتابگر روی عرشه
  بیرون می‌آید تا در هر هشت جهت خوانا باشد.

## فایل‌ها

همهٔ فایل‌ها PNG/RGBA با **پس‌زمینهٔ کاملاً شفاف** و فریم‌های `۱۲۸×۱۲۸`.

| فایل | فریم | اندازهٔ شیت | FPS | پخش | توضیح |
|---|---:|---:|---:|---|---|
| `tank_idle.png` | ۴ | 512×1024 | ۸ | حلقه‌ای | تکان خفیف تعلیق، پلک‌زدن، دود اگزوز |
| `tank_move.png` | ۶ | 768×1024 | ۱۲ | حلقه‌ای | غلتیدن زنجیر/چرخ + گرد و خاک |
| `tank_attack.png` | ۶ | 768×1024 | ۱۴ | یک‌بار | شارژ → شلیک لیزر → پس‌لرزه و دود |

`atlas_tank_iso.png` (+ `.json`) و `manifest.json` فرادادهٔ کامل (ابعاد، محور، جهت‌ها، پالت).

### چیدمان شیت

شبکه‌ای مثل پک برج‌ها: **ردیف = جهت (۰..۷)** و **ستون = فریم**.

```
             f0        f1        f2        f3   (f4, f5 در move/attack)
 dir 0 (E)  [128x128] [128x128] [128x128] [128x128] ...
 dir 1 (SE) ...
 dir 7 (NE) ...
```

جهت‌ها ساعت‌گرد از شرق: `0=E، 1=SE، 2=S (رو به دوربین)، 3=SW، 4=W، 5=NW، 6=N، 7=NE`.
مرکز چرخش بدنه روی زمین در پیکسل **(64, 99)** است؛ اسپرایت را با `centered=false` و
`offset` متناسب بگذار تا پاها روی کاشی زمین بنشینند.

> پک برج‌ها (`assets/turrets_iso/`) و دشمن قدیمی (`assets/enemy_soldier_cartoon/`) دست‌نخورده‌اند.

## ساخت مجدد و بررسی

```bash
pip install pillow
python3 tools/generate_iso_enemy_tank_sprites.py            # سه شیت + اطلس + مانیفست + پیش‌نمایش
python3 tools/generate_iso_enemy_tank_sprites.py --no-gif   # سریع‌تر، بدون GIF
```

این مولد قلم، دوربین، گرادیان و افکت‌های مشترک را از `tools/generate_iso_tower_sprites.py`
`import` می‌کند؛ یعنی خط دور، نور و پرسپکتیو هر دو پک از یک منبع می‌آید.

در پایان، خروجی خودکار بازرسی می‌شود: اندازهٔ فریم‌ها، RGBA بودن، خالی نبودن فریم،
**بریده‌نشدن پیکسل جامد روی لبهٔ کادر** و **یکسان نبودن فریم‌های یک انیمیشن**. اگر بررسی
رد شود، اجرا با کد ۱ تمام می‌شود (قابل استفاده در CI).

## نمونهٔ وصل‌کردن (Godot 4)

```gdscript
const FRAME := 128
var tex: Texture2D = load("res://assets/enemy_tank_iso/tank_move.png")

func frame(dir: int, f: int) -> AtlasTexture:
    var a := AtlasTexture.new()
    a.atlas = tex
    a.region = Rect2(f * FRAME, dir * FRAME, FRAME, FRAME)
    return a
# Sprite2D: centered = false، offset = Vector2(-64, -99) تا مرکز بدنه روی زمین بیفتد

func dir_to(target: Vector2) -> int:
    var d := Vector2(target.x - global_position.x, (target.y - global_position.y) / 0.5)
    return int(round(rad_to_deg(d.angle()) / 45.0)) % 8   # 0=شرق ... 7=شمال‌شرق
```
