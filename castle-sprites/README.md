# castle-sprites — قلعهٔ اصلی کارتونی (تاور دیفنس)

اسپرایت‌های قلعهٔ اصلی بازی تاور دیفنس، سبک کارتونی دست‌کشیده (الهام‌گرفته از
Kingdom Rush / Clash Royale)، نمای بالا ایزومتریک، پس‌زمینهٔ شفاف، ۵۱۲×۵۱۲ پیکسل،
PNG با کانال آلفا — آمادهٔ Import در Construct 3.

## فایل‌ها

| فایل | سطح | ویژگی‌های بصری |
|---|---|---|
| `castle_level_1.png` | ۱ | قلعهٔ کوچک پایه، دیوارهای ساده، میلهٔ پرچم خالی (بدون پرچم) |
| `castle_level_2.png` | ۲ | دیوارهای بزرگ‌تر، برجک‌های دیدبانی چوبی، یک پرچم آبی |
| `castle_level_3.png` | ۳ | برج‌های سنگی با سقف آبی، دو پرچم آبی، رون‌های آبی درخشان |
| `castle_level_4.png` | ۴ | قلعهٔ سنگین با تقویتهای آهنی، سه پرچم آبی، رون‌های بنفش درخشان |
| `castle_level_5.png` | ۵ | قلعهٔ عظیم با تزئینات طلایی، چهار پرچم طلایی، رون‌های طلایی، کریستال انرژی |
| `preview_castles.png` | — | ورق پیش‌نمایش هر ۵ سطح روی زمینهٔ شطرنجی (نمایش شفافیت) |

همهٔ سطح‌ها: سکوی صافِ خالی روی سقف برای نصب برج دفاعی، میلهٔ پرچم روی سقف،
بافت سنگی با ترک و خزه، بدون زمین/سایه/کاراکتر/رابط کاربری.
پیشرفت اندازه: سطح ۱ کوچک‌ترین ← سطح ۵ بزرگ‌ترین (هم‌تراز کف، وسط‌چین).

## خطوط تولید

- `raw/` — خروجی خام تصویرسازی با پس‌زمینهٔ کلید ماژنتا (#FF00FF).
- `csproc.py` — پردازش: حذف پس‌زمینه (فlood-fill از حاشیه + باند لبهٔ نرم +
  پاک‌سازی رنگ لبه)، برش به محتوا، مقیاس پلکانی هر سطح، چینش هم‌تراز کف روی
  بوم شفاف ۵۱۲×۵۱۲، و ساخت ورق پیش‌نمایش.

```bash
pip install pillow numpy scipy
python3 csproc.py
```

## نکتهٔ Construct 3

Origin پیشنهادی: وسط-پایین (bottom-center) تا هنگام تعویض سطح، قلعه روی همان
خط زمین بماند؛ کف همهٔ اسپرایت‌ها روی y=503 بوم ۵۱۲×۵۱۲ است.
