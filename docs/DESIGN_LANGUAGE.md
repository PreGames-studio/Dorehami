# زبان طراحی دورهمی

یک زبان، پنج ماژول. مرجع: **پوستهٔ اپ + شطرنج**. هر ماژولی که از این اعداد فاصله بگیرد، تناقض است نه سلیقه.

---

## ۱. رنگ‌ها (روشن)

| نقش | کد | کاربرد |
|---|---|---|
| `primary` | `#D9480F` | دکمهٔ اصلی، لینک، برجسته‌سازی |
| `onPrimary` | `#FFFFFF` | متن روی نارنجی |
| `primaryContainer` | `#FFE08A` | قرص انتخاب‌شده، نشان فعال |
| `secondary` | `#0E8F87` | لهجهٔ دوم، تأیید |
| `tertiary` | `#7B4CC2` | لهجهٔ سوم، نشان‌های ویژه |
| `background` | `#FFF4DC` | پس‌زمینهٔ کاغذی |
| `onBackground` | `#3A2A12` | متن روی کاغذ |
| `surface` | `#FFFFFF` | کارت شیشه‌ای |
| `onSurface` | `#2E2415` | متن اصلی |
| `surfaceVariant` | `#FFE9C2` | کارت ثانویه، فیلد ورودی |
| `onSurfaceVariant` | `#5B4B33` | متن کم‌رنگ |
| `outline` | `#C9A96B` | خط دور کارت (۱dp) |
| `error` | `#B3261E` | خطا و هشدار |

روشن/تیره از تنظیم سیستم پیروی می‌کند (`isSystemInDarkTheme()`).

## ۳. تایپوگرافی

- فونت: **Vazirmatn** (regular / medium / bold) — همه‌جا، بدون استثنا.
- مقیاس: **×۱٫۱۵** روی `Typography()` متریال. همین یک عدد در پوستهٔ اپ، شطرنج، حکم، پانتومیم و تخته‌نرد.
- اعداد فارسی فقط از `toPersianDigits()`؛ هیچ رقم لاتین در متن کاربر.

## ۴. کارت و پنل

```
surface.copy(alpha = 0.82f)      // شیشهٔ نیمه‌شفاف روی تصویر
border(1.dp, outline.copy(alpha = 0.72f))
RoundedCornerShape(24.dp)
```

کارت کدر سفید فقط جایی که تصویر پشتش نیست (دیالوگ، برگهٔ تنظیمات).

## ۵. پس‌زمینه

تصویر تمام‌صفحه + پردهٔ کاغذی سه‌مرحله‌ای + سه هالهٔ رنگی:

```
background α = 0.18 / 0.12 / 0.32   (عمودی)
primary   هاله در بالا-راست
secondary هاله در پایین-چپ
tertiary  هاله در پایین-راست
```

تصویرها در `res/drawable-nodpi` (بدون مقیاس چگالی)، پرتره ۹:۱۶، روشن و روزانه — نه صحنهٔ شبانه.

## ۶. وضعیت ماژول‌ها

| ماژول | پالت | مقیاس متن | پس‌زمینه | وضعیت |
|---|---|---|---|---|
| پوستهٔ اپ (خانه، انتخاب بازی، تنظیمات، فروشگاه) | اعداد بخش ۱ و ۲ | ۱٫۱۵ | آرت روشن | ✅ |
| شطرنج | همان اعداد، روشن + تیره | ۱٫۱۵ | آرت + پردهٔ ۰٫۱۸/۰٫۱۲/۰٫۳۲ | ✅ مرجع |
| پانتومیم | همان اعداد، روشن + تیره | ۱٫۱۵ | آرت + پردهٔ قوی‌تر (۰٫۲۲/۰٫۴۸) برای خوانایی متن روی آرت شادتر | ✅ (پرده عمداً کمی تیره‌تر) |
| تخته‌نرد | همان اعداد، روشن | ۱٫۱۵ | آرت تازهٔ روشن + پردهٔ ۰٫۱۸/۰٫۱۲/۰٫۳۲ | ✅ (این دسته اصلاح شد) |
| حکم | **پالت تیرهٔ میز** `#1E1A26` / `#2A2433` + طلایی `#FFB86B` | ۱٫۱۵ | عکس میز فرش‌دار | ⚠️ تنها استثنای عمدی: میز شبانهٔ حکم |

## ۷. چک‌لیست ماژول جدید

1. پالت را از بخش ۱/۲ بردار؛ رنگ تازه فقط برای **متریال شیء** (تخته، مهره، فرش) مجاز است.
2. `Typography()` را با ضریب ۱٫۱۵ و Vazirmatn بساز.
3. پنل = شیشهٔ ۰٫۸۲ + حاشیهٔ ۱dp + شعاع ۲۴dp.
4. پس‌زمینه = آرت روشن + پردهٔ ۰٫۱۸/۰٫۱۲/۰٫۳۲ + سه هاله.
5. روشن/تیره از سیستم؛ اگر ماژول فقط یک حالت دارد، باید دلیل داشته باشد و در همین سند ثبت شود.
6. هیچ گلیف وابسته به فونت (♛ ⌁ ✓) در برچسب‌ها؛ آیکن با `Canvas` یا ایموجی.
